## B. ありがとう手帳（新機能）

### 決まったこと

**入口**
- タイトル画面にタイルを追加する。絵文字は 📒、名前は「ありがとう てちょう」（各言語の名前は実装時に訳す）。

**毎日のミッション**
- 毎日 0時に新しいページになる（シールやさんの入れ替えと同じ区切り）。
- 候補の中から **日替わりで3個**。選び方:
  - 1個目: 「🙏 ありがとう」から必ず
  - 2個目: 「👋 ことば・やさしさ」から
  - 3個目: 残り全部（ありがとうを含む）から
- できたらタップでチェック ✅（花丸スタンプ 💮 の演出）。
- **引き直しできる**: チェック済みのミッションは残し、まだのものだけ入れ替える。
  - ごほうびは「その日のチェック数」で決まるので、引き直してもごほうびを何度ももらうことはできない。
  - 引き直せるので、自然と得意なミッションに偏っていく（それも面白さとして受け入れる）。

**ごほうび（エネルギー）**: その日にチェックした数で、合計が次のようになる（A案）。

| チェック数 | その日の合計 | そのとき増える量 |
|---|---|---|
| 1個 | 10 kcal | +10 |
| 2個 | 30 kcal | +20 |
| 3個（全部） | 100 kcal | +70 |

- 本当にやったかは確かめない。チェックリストを見てどう感じるかはその子次第。

**だれに？**
- 「だれ ✓」のミッションは、チェックするときに相手を選ぶ（文字入力はしない）。
- 選択肢: 👨 おとうさん / 👩 おかあさん / 🏠 おうちの ひと / 👴 おじいちゃん / 👵 おばあちゃん / 👦 きょうだい / 🧒 ともだち / 🧑‍🏫 せんせい / 🙂 ほかの ひと

**過去の記録**
- カレンダーで振り返れる。

**集計（まとめ）**
- 達成したミッションの数と、その内容の内訳を見せる。
  - 例:「いままでに できた ミッション ◯こ」
  - ミッションごとの回数（🙏 だれかに「ありがとう」を いおう … ◯かい）
  - 相手ごとの回数（👩 おかあさん … ◯かい）
  - 期間は「いままで ぜんぶ」と「こんげつ」の2つを切り替えて見せる。
  - 内訳は回数の多い順に並べる。

**手帳の見た目**
- 手帳をイメージしたタブ構成: 「きょう」「カレンダー」「まとめ」。
- タブは手帳の上に並んだ付箋の形。付箋をタップすると、ページがめくれるように入れ替わるアニメーション。

**さいしょから はじめる（進捗リセット）**
- 手帳の記録（毎日のチェック・相手・カレンダー・集計）もすべて消す。
- 確認文にそのことをはっきり書く。
  - 「さいしょから はじめる」: 「きろくも シールも エネルギーも ありがとう てちょうも ぜんぶ きえます。よろしいですか？」
  - 「ハイスコアをリセット」（手帳は消さない）: 「ぜんぶのゲームの きろくが きえます。シールと エネルギーと ありがとう てちょうは のこります。」

### 案のまま進めるもの（指摘がなければ確定）
- **チェックの取り消し**: 外せる。一度もらったエネルギーは減らさず、外して付け直しても二重にはもらえない（その日にもらった段階を覚えておく）。
- **相手の選び方**: 複数選べる。必ず1人は選ぶ（「ほかの ひと」があるので選べないことはない）。
- **きのうのページ**: 次の日にふりかえってチェック・取り消しができる（「おやすみ」のように、その日のうちにチェックできないミッションのため）。チェックもれがあれば「きょう」のページの下に「📖 きのうの ページ」として出す。ごほうびもきのうのページの段階で渡す。引き直しは「きょう」だけ。
- **おととい より前のページ**: 見るだけ。
- **カレンダー**: 月ごとの表に、その日のチェック数でスタンプ（0個＝なし、1〜2個＝小さい花、3個＝花丸）。日付をタップすると、その日のミッションと相手が見られる。
- **引き直しの回数と単位**: 何回でもできる。まだのものをまとめて入れ替える（ボタン1つ）。
- **0回のミッション・相手**: 集計の一番下に薄く出す（「まだ やっていない ミッション」が分かるように）。
- **15言語**: ミッション文・相手の名前・タイル名・付箋の名前を実装時にまとめて翻訳する。
