## 3.5 絵を端末に対して縦向きに止める（シール帳の紙・かべがみ）

ボタンや文字は画面と一緒に回り、絵だけが端末に貼りついたまま動かないこと。

- [ ] シール帳であそぶ画面で横にすると、紙が90°回って画面いっぱいに重なり、端末から見て絵が動かない（左右どちらに回しても）
- [ ] 横から反対の横へ一気に180°回しても、絵が逆さにならない
- [ ] 横のまま、なぞったところに線が引ける
- [ ] 横のまま、シールを長押しで動かせる・トレイへ戻せる・トレイから引き出して離した場所に置ける
- [ ] かべがみをオンにして横にすると、かべがみの絵も端末に対して止まって見える
- [ ] 分割表示・Stage Manager のウィンドウでも、絵がゆがまない
- [ ] 上下逆さ: iPad・ホームボタンのある iPhone では 180°回る。顔認証の iPhone は iOS が逆さに対応していないので回らない（正しい動き）

## 3.6 iCloud 同期と、もう一度の同意

準備: 同じ Apple アカウントでサインインした端末（シミュレータ可）を2台。CloudKit Console で開発環境（Development）のデータを見られるようにしておく。

### 同意
- [ ] v1.5.0 から更新すると、最初の起動で同意画面がもう一度出る（新しい文に「iCloud にだけ保存できます」がある）
- [ ] 同意するまでは iCloud につながらない（CloudKit Console に記録が増えない）
- [ ] 新しくインストールした人は、今までどおり同意画面が1回だけ出て、「はじめまして」のプレゼントがもらえる
- [ ] 「プライバシーポリシー・免責事項を読む」の中身が新しい文になっている（15言語のどれか数個も見る）

### 同期
- [ ] 1台目で遊ぶと、CloudKit Console の AppData ゾーンに記録（page-01〜12, wallpaper, stickers, shop, energy, scores, thanks, game）ができる
- [ ] 2台目（まだ遊んでいない）を開くと、聞かれずに1台目の記録が届く（シール帳の絵・シール・エネルギー・ハイスコア・てちょう・かべがみ）
- [ ] 1台目でシール帳に描くと、2台目でアプリに戻ったときに同じ絵になる（開いているページも描き直される）
- [ ] 2台でオフラインのまま別のページに描き、両方オンラインにすると、両方のページが残る
- [ ] 同じページを2台で描くと、あとで描いたほうが残る
- [ ] ハイスコアは、2台の記録のよいほうになる（片方で新記録を出しても、もう片方の記録が下がらない）
- [ ] シールやさんで片方が買ったシールは、もう片方でも売り切れになる
- [ ] 同じ日のログインボーナスを、2台目でもう一度もらえない

### 2択・オン／オフ・リセット
- [ ] 両方の端末に記録があって、はじめてつなぐと、設定の「iCloud に ほぞん」の下に「えらんでください」と「えらぶ」が出る（勝手には混ざらない）
- [ ] 「iCloud の きろくを もどす」で iCloud の記録になる／「この たんまつの きろくで うわがき」で iCloud がこの端末の記録になる／「あとで」で何も変わらない
- [ ] 「さいしょから はじめる」の確認に「iCloud の きろくは のこります」が出る
- [ ] リセットすると「iCloud に ほぞん」がオフになり、もう1台の端末の記録は消えない
- [ ] オンに戻すと2択が出て、「もどす」でリセット前の記録が戻る
- [ ] iCloud にサインインしていない端末では「iCloud に サインインしていません」と出て、ふつうに遊べる
- [ ] 機内モードでも、すべてのゲームで遊べる（つながったときに送られる）

## 3.7 ゲームごとの「きょう はじめての ボーナス」

対象は10種類: MAKE10（30びょう・10びょうは別々）・絵文字クイズ・もぐら叩き・迷路・Pinball・CoinDrop・指令じゃんけん・テンパズル・どうぶつめくり。量は 50kcal（GameDailyBonusTuning.amount）。

### タイトル画面の 🎁
- [ ] その日まだ最後まで遊んでいないゲームのカードの右下に 🎁 が出る
- [ ] シールやさん・ガチャ・ありがとう てちょう・シール帳・シールじてん には 🎁 が出ない
- [ ] 10びょうモードは、解放後にカードが出たときに 🎁 が付く
- [ ] 縦・横（iPad の横長の並べ方）とも、🎁 がエネルギー表示や文字に隠れない
- [ ] VoiceOver で 🎁 が「きょう はじめて あそぶと ボーナスが もらえるよ」と読まれる

### もらえるとき・もらえないとき
- [ ] 10種類それぞれ、その日はじめて最後まで遊ぶと（結果画面が出ると）エネルギーが 50 増える
- [ ] 結果画面の大きな「+○○kcal」にボーナスの分も入り、下に「🎁 きょう はじめての ボーナス +50」が出る
- [ ] スコアが 0 でも、最後まで遊べば「🎁 きょう はじめての ボーナス +50」だけが出る
- [ ] どうぶつめくりは、全部そろえてクリアしたときにもらえる
- [ ] 同じ日に同じゲームをもう一度遊んでも、ボーナスの行は出ない（エネルギーも 50 増えない）
- [ ] 遊び終わってタイトル画面に戻ると、そのゲームの 🎁 が消えている
- [ ] ゲームを始めてすぐ戻る（最後まで遊ばない）と、もらえず、🎁 も残る
- [ ] MAKE10 の30びょうと10びょうは、それぞれ別にもらえる
- [ ] 端末の 0時をまたぐと（または翌日に開くと）、また 🎁 が付き、もらえる

### iCloud・リセット
- [ ] iPhone でもらったゲームは、iPad でアプリに戻ったときに 🎁 が消え、同じ日にはもらえない
- [ ] 2台をオフラインで使って同じゲームのボーナスを両方でもらったあと、つなぐと、受け取った日がそろう（エネルギーは「あとで変えたほう」になる）
- [ ] 「さいしょから はじめる」のあとは、その日でも、どのゲームにも 🎁 が付き、またもらえる

## 3.8 シールをエネルギーに交換（シールじてん）

1枚 30kcal（StickerExchangeTuning.kcalPerSticker）。交換できるのは、つかっていない（シール帳の一覧の下の段にある）シールだけ。

### 1まい こうかん
- [ ] シールじてんで、見つけたシールを押すとカードが開く（まだのシール＝黒いシルエットは押しても何も起きない）
- [ ] カードに「つかっていない ○ まい ・ ぜんぶ ○ まい」が出る（貼ってある分は「ぜんぶ」にだけ入る）
- [ ] 「1まい こうかん（🔥+30）」で、エネルギーが 30 増え、枚数が1つ減り、「🔥 +30kcal」が一瞬出る
- [ ] ぜんぶ貼ってあるシールは、ボタンが押せず「はってある シールは こうかん できないよ」と出る
- [ ] シール帳のページやゲーム画面に貼ったシールは、交換しても消えない

### 未使用を ぜんぶ こうかん
- [ ] 上の「つかっていない シール ○ まいを ぜんぶ こうかん（+○）」で確かめが出て、「やめる」なら何も変わらない
- [ ] 「こうかん する」で、つかっていないシールがぜんぶエネルギーに変わる（貼ってあるシールは残る）
- [ ] つかっていないシールが0枚のときは、ボタンが押せない

### 自動交換
- [ ] 交換してある種類が0枚になると「0まいに なったよ」「これから ガチャで でたら じどうで エネルギーに かえる？」と聞かれる（まとめて交換したときは、0枚になった種類をまとめて1回だけ聞く）
- [ ] 「じどうで かえる」にすると、じてんのその種類の右上に 🔥 が付く。カードのトグルでオン・オフできる
- [ ] 自動交換の種類がガチャで出ると、シールばこに入らず、うすく表示されて 🔥 が付き、「○ まいは エネルギーに かえたよ（🔥+○kcal）」と出る
- [ ] 自動交換の種類は、次の日からシールやさんの品ぞろえに並ばない
- [ ] どうぶつめくりのごほうびで選んだシール・シールやさんで買ったシールは、自動交換にしていても、ふつうにシールばこに入る

### 見つけた記録・NEW
- [ ] 交換して0枚にしても、じてんでは色つきのまま（黒いシルエットに戻らない）。「あつめた シール ○ / ○」も減らない
- [ ] 0枚にした種類がガチャで出ても「NEW」は付かない
- [ ] v1.5.0 から更新した直後、じてんの「見つけた」が、更新前に持っていたシールと同じになっている

### iCloud・リセット
- [ ] 交換・自動交換・見つけた記録が、もう1台の端末にも届く（見つけた記録は2台の分が合わさる）
- [ ] 「さいしょから はじめる」で、自動交換と見つけた記録も消える

## 3.9 どうぶつめくりの カードえらび（5×5・せいざ・つき）

5×5 はまん中に Flying Dev Lab のロゴ（押せない）を置き、まわりの24枚（12組）で遊ぶ。むずかしさ ボーナスは MemoryTuning.hardClearBonus（100kcal）。

### スタート画面
- [ ] 「カードを えらんで スタート！」の下に、6つのボタン（🐘 どうぶつ 4×5 / 🐉 どうぶつ 5×5 / 🍓 くだもの / ♈ せいざ / Jan つき（えいご） / 睦月 つき（かんじ））が並ぶ。iPhone の縦では 3つずつ2行。せいざ・つき には「🔥+100」
- [ ] ボタンを押すと、すぐにその種類でゲームが始まる（スタートボタンはない）
- [ ] 前回あそんだ種類のボタンに茶色の枠が付いている（結果画面の「カードを えらぶ」で戻ったときも）
- [ ] iPhone の横向きでは、左に遊び方・右にボタンが並ぶ（はみ出すときはスクロール）
- [ ] 画面・読み上げのどこにも「干支」の言葉が出ない

### 盤面
- [ ] どうぶつ 4×5: いままでどおり 10組（ロゴなし）
- [ ] どうぶつ 5×5: 🐁🐇🐅🐂🐉🐍🫏🐏🐒🐓🐕🐖 の12組。まん中にロゴ
- [ ] くだもの: 15種（🍎🍊🍋🍌🍉🍇🍓🍒🍑🍍🥝🍈🥭🫐🍋‍🟩）から毎回ちがう12組。まん中にロゴ。むずかしさ ボーナスはなし
- [ ] せいざ: ♈〜♓ の12組
- [ ] つき（えいご）: January〜December。左上に小さく月の数字（1〜12）が付く。September など長い単語も1行に収まり、数字と重ならない（iPhone の縦でも読める大きさか）
- [ ] つき（かんじ）: 睦月〜師走。左上に小さく月の数字（1〜12）が付く。日本語以外の言語でも同じ漢字が出る
- [ ] まん中のロゴを押しても何も起きない。連続の倍々は12組までそのまま（12れんぞくで +2048）

### クリア・結果画面
- [ ] せいざ・つき をクリアすると、内訳が「あそんだぶん +○ ・ むずかしさ ボーナス +100」になる。どうぶつ は内訳なし（いままでどおり）
- [ ] えらべるシール: どうぶつ＝そろえた動物、くだもの＝15種すべて（5列×3行。盤面に出なかった3種もえらべる）、せいざ＝♈〜♓、つき＝季節の絵文字（🎍⛄🎎🌸🎏☔🎋🍉🎑🎃🍁🎄）。12まいは 6列×2行
- [ ] 「もういちど」は同じ種類で始まる。その下の「カードを えらぶ」でスタート画面に戻る
- [ ] 「きょう はじめての ボーナス」は、どの種類で遊んでも1日1回だけ（どうぶつめくり1つとして）

### シール
- [ ] 新しいシール（🐁🐇🐅🐂🐍🐏🐒🐕🐖・♈〜♓・☔🎎🎑）が、ガチャ・シールやさん・じてんに出る。じてんの総数が 21 増える

## 4. かべがみ（v1.5.0 の不具合の修正）

かべがみを「あり」にして、文字の後ろに半透明の座布団が敷かれ、読めること。

- [ ] テンパズル: タイトル、「1 / 10」、「モード選択に戻る」、押せない「= 10？ こたえる」
- [ ] どうぶつめくりの結果: 🎉よくできました、すきなシールをえらんでね、選んだあとの文字
- [ ] シールやさん: 「のこり ◯ / 10」
- [ ] 指令じゃんけん: カウントダウン、「0 / 30」、かって！／まけて！（上の札も）、タイマー、+5秒、切り替えの表示
- [ ] シール帳: 見出し、枚数、絵文字の列、案内（文字が濃く、座布団が重ならない）
- [ ] かべがみ「なし」では、どの画面も v1.5.0 と同じ見た目
