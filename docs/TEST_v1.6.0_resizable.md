## 1. 向きの制御

### iPhone
- [ ] どの画面でも縦のまま（横にしても回らない）

### iPad（全画面）
- [ ] タイトル画面で ⌘← / ⌘→ を押すと横向きになる
- [ ] 横向きのまま Pinball を開くと、縦向きに戻る
- [ ] 横向きのまま CoinDrop を開くと、縦向きに戻る
- [ ] 横向きのまま TenPuzzle を開くと、縦向きに戻る
- [ ] 上の3つのゲームからタイトル画面に戻ると、また横向きにできる
- [ ] 上の3つ以外のゲームは、横向きのまま遊べる

### iPad（分割表示・Stage Manager のウィンドウ表示）
- [ ] ウィンドウの右下のつまみで大きさを変えられる
- [ ] 縦固定の3つのゲームを横長のウィンドウで開いても、盤面が中央に収まり、崩れない
- [ ] 左上の操作ボタン（●●●）に、戻るボタン「＜」が隠れない（シール帳であそぶ画面も含む）

## 3. iPhone Duo（iOS 27.1）

Device Hub で、開く・閉じる・回す・折り曲げる、を切り替えて確かめる。

- [ ] 閉じた状態（ふつうの iPhone と同じ形）で、すべての画面が今までと同じ
- [ ] 開いた状態で、時刻とカメラ（右側に縦に並ぶ）に、ボタンや文字が隠れない
- [ ] ゲームの途中で開閉しても、落ちない
- [ ] ゲームの途中で開閉しても、スコア・残り時間・盤面の状態が保たれる
  - [ ] MAKE10（タイマーが止まったり、進みすぎたりしない）
  - [ ] Pinball（ボールが壁を抜けない）
  - [ ] CoinDrop（コインが壁を抜けない）
  - [ ] 迷路
  - [ ] どうぶつめくり（めくったカードの並びが変わらない）
- [ ] 縦固定の3つのゲームを開いた状態で遊ぶと、盤面が中央に収まる
- [ ] お絵かき・シールが、開閉の前後でずれない（※ 線とシールのずれは Part B で直す予定。今は「ずれる」なら記録だけする）

## 4. かべがみ（v1.5.0 の不具合の修正）

かべがみを「あり」にして、文字の後ろに半透明の座布団が敷かれ、読めること。

- [ ] テンパズル: タイトル、「1 / 10」、「モード選択に戻る」、押せない「= 10？ こたえる」
- [ ] どうぶつめくりの結果: 🎉よくできました、すきなシールをえらんでね、選んだあとの文字
- [ ] シールやさん: 「のこり ◯ / 10」
- [ ] 指令じゃんけん: カウントダウン、「0 / 30」、かって！／まけて！（上の札も）、タイマー、+5秒、切り替えの表示
- [ ] シール帳: 見出し、枚数、絵文字の列、案内（文字が濃く、座布団が重ならない）
- [ ] かべがみ「なし」では、どの画面も v1.5.0 と同じ見た目
