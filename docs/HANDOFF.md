## v1.6.0 に入ったもの

### 横画面・ウィンドウ・iPhone Duo
- iPad・iPhone の横向き、iPad の分割表示・Stage Manager、iPhone Duo を開いた画面に対応。
  並べ方は「端末の向き」ではなく「使える場所が横長か」（`DS.isWide`）で切り替える。

## v1.5.0 に入るもの（TestFlight ビルド1 のあとに入れたもの）

### iPad のレイアウト
- MAKE10（30秒・10秒）とクイズのプレイ画面を、画面の大きさに合わせて拡大（iPhone は変わらない）。
  `DesignSystem.swift` の `layoutScale` / `.scalesForLargeScreen()`。拡大の上限は `DS.maxLayoutScale`（1.8）。

### どうぶつめくり
- そろえるごとにエネルギー。1 → 2 → 4 → … → 512 kcal（連続で倍々、はずすと 1 から）。`EnergyRewards.memoryFirstReward`。
- クリア後は、エネルギーの数え上げの下で、好きな動物シールを1匹えらぶ（「シール帳に いれたよ」→「もういちど」）。
  一度シールえらびを外したが、ユーザーの希望で戻して両方にした。

### シールやさんの「ひとこと」
- 👆 の吹き出し。全17話を、シールやさんを開くたびに1話ずつ順番に（最後まで読んだら1話目へ）。
  ⓪ このゲームでは エネルギーで ガチャ・シール → ① エネルギーって なに？ → ② はかりかた（cal・kcal）→ ③ たべものの エネルギー → ④ からだは いつ つかう？ → ⑤ 1にちに どれくらい？
- 数字は国際的な目安を「やく」「ぐらい」でざっくり。アレルギーにつながる話題は入れない。
- `StickerShopView.swift` の `ShopTipBubble`。どこまで読んだかは `UDKey.shopTipIndex`（「さいしょから はじめる」で1話目に戻る）。

### タイトル画面
- 自動デモで 👆 がカードをスワイプし、それに合わせてカードが動く（入れ替え・飛ばし）。`TitleView.swift` の `demoSwipe`。
- 新しいタイルは、ロゴのすぐ後ろに入る。
- お知らせ・休憩のカードが重なっているあいだは、自動デモを止める。

### 休憩のおしらせ
- 30分つづけて遊ぶと 👆「30 ぷん あそんだよ！」＋休み方のひとこと（目・のび・水）。
- 出すのはタイトル画面と、全ゲームの結果画面（エネルギーの数え上げが終わってから）。ゲームの途中には出さない。
- アプリが裏に回ったら（ホーム画面・アプリ切り替え・画面ロック）すぐ 0 から数え直す。カードを閉じても数え直す。
  通知センター／コントロールセンターを引き出しただけではリセットしない。
- 設定に「きゅうけいの おしらせ」のオン／オフ（保護者が集中させたいとき用、初期値オン）。
- `App/BreakReminder.swift`（時間は `BreakReminderTuning.playLimit`）、`App/BreakReminderView.swift`。

### 迷路
- ゲームは60コマ/秒に固定（iPad Pro など120コマの端末でも同じ速さ）。
- 各ステージの11匹目から、赤 → 青 → いつもの敵 の順に出す（`WALL_FOLLOWER_FROM` / `LATE_SPAWN_ORDER`）。
  赤は右手、青は左手を壁につけて迷路を巡回する（膠着を防ぎ、難しくするため）。迷路は一本道で全部回れる作りなので、壁沿いに迷路全体を回り続ける。
- 同時に出る敵の数は、いまも上限なし（ステージ数 × 2）。出現の間隔は 3.5 / 3 / 2.5 / 2 秒（ステージ 1 / 2〜3 / 4〜5 / 6〜）。
- 衝撃波は1発3秒でたまり、ためておける。1回のタップで1発使う。ためられる数と届く距離はライフで変わる（`swMaxStockByHp` / `swRangeByHp`）。
  ライフ3：1発・5マス、ライフ2：2発・6.5マス、ライフ1：3発・8マス。ステージ開始時は、ためられるだけたまっている。
  ゲージは次の1発までの進み具合、💥 の数はいま撃てる数。

### クイズ
- 国旗: 全ての国連加盟国 ＋ バチカン・パレスチナ・コソボ・台湾・香港・ニューカレドニア（199）。キプロスはヨーロッパ、コーカサス3国はアジア。
- そっくりな旗はわざと同じ問題に並べる（`Quiz/QuizLookalikes.swift`）。絵文字では見分けられないインドネシアとモナコ、ルーマニアとチャドは並べない。
- 空港コード: 定期便のある空港だけ。日本83・中国261・ドイツ38・フランス49・アメリカ679・オランダ11（カリブ海の地域を含む）・世界4133。
  名前は日本語・英語・現地の言葉の3つ。「世界」だけ都市名つき。作り方は `tools/airports/README.md`。
- カテゴリの問題が10より少ないときは、ある分だけ出す。

### お絵かきとかべがみ
- お絵かき画面の道具パネル（色・ペン・シールのトレイ）は、つまみをドラッグで動かせ、「ー」で 🎨 にたためる。位置とたたみ具合は保存。
- ヘッダーの 🖼️ で、いまの絵（背景色・線・貼ったシール）を画像にして「かべがみ」にする（`Sticker/WallpaperStore.swift`、保存先 Documents/wallpaper.png）。
- かべがみは `AppBackground` で、SharedFrame（タイトル・ゲーム・結果など全画面）とじゃんけんの全面の背景に出す。比率は変えずに画面いっぱい、はみ出しは切る。濃さは描いたまま。
  ヘッダーとフッターの帯は、かべがみの絵の背景色で塗る（文字が読みにくくならず、帯が絵になじむように。`WallpaperStore.bandColor`）。
  カードやボタンの半透明の塗りは `tintFill`（DesignSystem.swift）で塗り、かべがみのときだけ下に DS.bg を敷いて透けないようにしている。
  新しく半透明の塗りを足すときも `.fill(color.opacity(…))` ではなく `.tintFill(…)` を使う。
- 設定の「かべがみ（じぶんの絵）」でオン／オフ。一度もかべがみを作っていなければ押せない。
- 「さいしょから はじめる」では、お絵かきの線・かべがみ・お絵かき画面の背景色とパネルの位置も消す（確認文にも明記）。
- ⚠️ プロジェクトは iCloud Drive の中にあるので、ブランチを切り替えたあとなどに iCloud が「〇〇 2.swift」のようなコピーを作ることがある。
  ビルドで「Invalid redeclaration」が出たら、まずこのコピーを探して消す（`find . -name "* 2.swift"`）。

## 作業のメモ

### ビルドとシミュレータ
- プロジェクト `FDL-TenBlitz.xcodeproj`、スキーム `FDL-TenBlitz`、バンドルID `com.flyingdevlab.FDL-TenBlitz`。
- iPad のシミュレータ「iPad Pro 11 (iOS 27)」（`77966E91-7848-4DDA-9E34-8B31F77628DD`）。iOS 26.x のシミュレータでは絵文字が「?」になる。
- タップが1回分遅れて届くことが多い。画面が変わる操作のあとは、フッター（© の行）など何も起きない場所を一度たたくと次のタップが正しく届く。
- `xcrun simctl spawn … defaults` はアプリの保存場所と別なので効かない。テストデータはアプリのコンテナの
  `Library/Preferences/com.flyingdevlab.FDL-TenBlitz.plist` を、アプリを止めてから直接書き換える。
- 見たい画面へすぐ行くには、DEBUG ビルドを撮影モードで起動する: `xcrun simctl launch <端末> com.flyingdevlab.FDL-TenBlitz -ssScene quiz`（場面の一覧は `ScreenshotScene`）。
- シミュレータの設定（plist）を書き換えたあとは、設定の係を再起動する: `xcrun simctl spawn <端末> launchctl kill SIGKILL system/com.apple.cfprefsd.xpc.daemon`。

### 翻訳（Localizable.xcstrings）
- 15言語（ja, en, de, es, fr, hi, id, it, ko, nl, pt-BR, th, vi, zh-Hans, zh-Hant）。
- スクリプトで書き換えるときは、Xcode と同じ書式（`" : "` 区切り・空の `{}` の改行）で書き戻し、キーの並び順を変えない。
- `LocalizedStringKey` を文字列の埋め込み（`"\(…)"`）で作らない（キーが `%@` になってしまう）。`"prefix_" + rawValue` のようにつなぐ。

### コミット
- コミットしたら、作業中のブランチを origin へプッシュまでする。main はリリース済み（またはリリース直前）の版。次のバージョンは main から作業ブランチを作り、リリースしたら main にマージしてタグを付ける。
