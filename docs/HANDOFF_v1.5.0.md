最新コミット: `02bd6e4`（origin/main にプッシュ済み）

## v1.5.0 でやったこと

### エネルギー（kcal）
- 隠しポイントを「エネルギー🔥 ◯kcal」として表示（単位は全言語 kcal）。内部は 0.1kcal 単位（`balanceDeci`）、表示は切り捨て。
- ヘッダーに常時表示（20pt・外枠付き、タイトルの下）。シールやさん・ガチャでは非表示。
- 正解ごとに +1（リアルタイム）、クリア時に「正解数 × ゲーム別倍率」、全問正解 +100。結果画面に数え上げ演出（`EnergyRewardBanner`）。
- 倍率などの調整値は `MAKE10/Energy/EnergyStore.swift` の `EnergyTuning` / `EnergyRewards` に集約。

### シールの入手方法
- **ガチャ**: 1回 100kcal、「10かい」1,000kcal で11枚。全249種が同確率。10かいは紙吹雪。
- **シールやさん**: 1枚 200kcal。毎日10種（救済枠3＋ランダム枠7）、各1枚まで、全部もらうと「きょうは おしまい」。
- 手に入れたシールは「もっているシール」へ直送。旧来のゲーム後シール配布は廃止。
- シール 249種・17カテゴリ（`StickerCatalog.swift`）。
- **シールじてん**: カテゴリ別一覧、所有数「×N」、未入手は黒いシルエット。

### プレゼント・ボーナス
- ログインボーナス: 100kcal、前日も開いていれば 150kcal（`DailyBonus.swift`）。
- 新規インストール:「はじめまして」1,000kcal。
- 1.5.0 へ更新した人: 10,000kcal ＋ じゃんけん記録リセット（`AppMigration.swift`）。今後も毎月のアップデートで配る予定。

### ゲームごとの変更
- 四則テンパズル: ヒントなしの正解だけ数える（×20/×50/×100、全問正解 +1000）。
- ピンボール: 出現位置を高く、出た直後のゆっくりタイム、マルチボール（最大2個）、全部落ちたら残り回数が減る、フリッパー固まり修正、500点＝0.5kcal。
- じゃんけん: ノーミスのタイムだけ記録。
- 迷路: HUD を迷路の外へ（❤️/💔ライフ、大きな衝撃波ゲージ）。

### その他
