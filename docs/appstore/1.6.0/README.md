# App Store の文章（v1.6.0）

App Store Connect の言語ごとに、「アプリ名」「キーワード」「プロモーション用テキスト」「概要」「このバージョンの最新情報」を1ファイルにまとめている。
v1.6.0 からアプリ名が変わる（英語: Kids Games by Flying Dev Lab。各言語の名前は各ファイルの先頭）。
各ファイルの ```text の枠の中を、そのまま貼り付ける。

- 文字数の上限: アプリ名 30文字、キーワード 100文字、プロモーション用テキスト 170文字、概要 4,000文字、最新情報 4,000文字（すべて上限内）
- キーワードはカンマ区切り・カンマのあとにスペースを入れない。アプリ名に入っている言葉は入れない（名前だけで検索に出るため）。どの言語にも「MAKE10」（旧アプリ名）を入れている
- 絵文字は使わない（「■」「•」「・」は記号として使っている）

機能の呼び名（Sticker Corner、Danke-Heft、Chifoumi des consignes など）は、v1.6.0 の翻訳見直し後のアプリ内の表記に合わせている。
保護者向けの節（iCloud など）は、アプリ内の同意・ポリシーの文と同じく、敬語（Sie・vous・usted・u など）にしている。
アプリの中に地域別の言語がない場合（スペイン語（メキシコ）、フランス語（カナダ）、ポルトガル語（ポルトガル））は、
文章はその地域の言い方にし、機能名だけアプリの表記に合わせている（各ファイルの冒頭に違いをメモしている）。
