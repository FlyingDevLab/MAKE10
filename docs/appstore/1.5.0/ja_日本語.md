# 日本語

## プロモーション用テキスト

```text
遊ぶほどエネルギーがたまって、シールが集まる！毎日の「ありがとう てちょう」、世界じゅうの国旗クイズ、じぶんの絵を背景にできるおえかきも。広告なし・課金なし・オフラインで安心して遊べます。
```

## 概要

```text
こどものための、安心して遊べるゲームコレクションです。
広告なし・アプリ内課金なし・個人情報の収集なし。インターネットにつながなくても遊べます。

■ 収録ゲーム
・MAKE10 … 数字カードをタップして、合計10をつくろう
・モグラたたき … 出てきたモグラをすばやくタップ
・迷路（チーズクエスト）… チーズを集めよう。ためた衝撃波でネズミを撃退！
・ピンボール … フリッパーでボールを打ち返そう
・絵文字クイズ … どうぶつ、世界の国旗、空港コードに挑戦
・コインドロップ … コインを落として合体させよう
・指令じゃんけん … 「勝って！」「負けて！」の指令どおりに出せるかな？
・四則テンパズル … 4つの数字と ＋ − × ÷ で10をつくろう
・どうぶつめくり … 同じどうぶつをそろえる神経衰弱
・シール＆おえかき … シールを貼ったり、クレヨンで自由にお絵かき

■ ありがとう てちょう
毎日3つのミッションが届きます。「ごはんを つくってくれた ひとに ありがとう」「おやすみを いおう」など、身近な人への気持ちを伝える小さなミッションです。
できたらチェックして、だれに伝えたかを選びます。カレンダーやまとめで、これまでの「ありがとう」をふりかえることもできます。

■ じぶんの絵を かべがみに
お絵かきで描いた絵は、タイトルやゲームの背景にできます。
色やシールの道具は、動かしたり小さくたたんだりできるので、画面いっぱいに描けます。

■ エネルギーとシール
ゲームで遊ぶと「エネルギー」がたまります（単位は kcal）。
たまったエネルギーで、ガチャを回したり、毎日品ぞろえが変わる「シールやさん」でシールと交換したりできます。
シールは全249種類。「シールじてん」で集めたシールを見ることができます。
エネルギーは遊んだときにだけ増えます。お金で買う方法はありません。
シールやさんでは、「kcal ってなに？」をやさしく説明する ひとこと も読めます。

■ 世界を知るクイズ
国連加盟国すべての国旗（199か国・地域）と、日本・中国・ドイツ・フランス・アメリカ・オランダ、そして世界4,000以上の空港コードに挑戦できます。
そっくりな国旗が並ぶ問題もあるので、見分けるポイントを探しながら遊べます。
カテゴリは問題の少ない順に並んでいるので、やさしいものから少しずつ広げていけます。

■ 保護者の方へ
・30分続けて遊ぶと、ひとやすみを うながすおしらせが出ます（設定でオフにできます）
・効果音と振動は、設定でそれぞれオン・オフできます
・iPhone と iPad に対応しています
・15の言語で遊べます

■ ソースコードを公開しています
このアプリが広告を出さないこと、課金がないこと、外部と通信しないことを、だれでも確かめられるように、ソースコードを公開しています。
```
