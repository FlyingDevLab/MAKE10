# App Store の文章（v1.5.0）

App Store Connect の言語ごとに、「プロモーション用テキスト」「概要」「このバージョンの最新情報」を1ファイルにまとめている。
各ファイルの ```text の枠の中を、そのまま貼り付ける。

- 文字数の上限: プロモーション用テキスト 170文字、概要 4,000文字、最新情報 4,000文字（すべて上限内）
- 絵文字は使わない（「■」「•」「・」は記号として使っている）

機能の呼び名（Sticker Corner、Danke-Heft など）は、アプリの中の各言語の表記に合わせている。
アプリの中に地域別の言語がない場合（スペイン語（メキシコ）、フランス語（カナダ）、ポルトガル語（ポルトガル））は、
文章はその地域の言い方にし、機能名だけアプリの表記に合わせている（各ファイルの冒頭に違いをメモしている）。
